# Livrable

Un fichier au format **TXT** ou **PDF** contenant les liens vers :

1. Votre code source sur **GitHub** de la bibliothèque React convertie depuis le plugin jQuery sélectionné (un seul plugin doit être converti).
2. Votre **projet complet** sur GitHub.
3. La bibliothèque React convertie publiée sur **npm** (ou **GitHub Packages**).

Un **rapport de performance Lighthouse** au format PDF de HRnet fonctionnant **avant** et **après** la conversion de la bibliothèque.
